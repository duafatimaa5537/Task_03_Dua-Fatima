Project 3: SQL Data Analysis

Project Overview: <br>
This project focuses on analyzing a sales dataset using SQL to extract meaningful business insights. SQL queries were used to filter, group, and summarize the data and evaluate sales performance across different products, payment methods, and referral sources.

Objectives: <br>
- Analyze product-wise sales performance <br>
- Calculate total revenue and number of orders <br>
- Compare sales across different payment methods <br>
- Analyze product performance from Instagram referrals <br>
- Perform product-specific sales analysis

SQL Skills Used: <br>
- SELECT <br>
- WHERE <br>
- GROUP BY <br>
- ORDER BY <br>
- COUNT() <br>
- SUM()  <br>
- AVG() <br>
- Filtering and data grouping

Key Analysis: <br>
- Product-wise sales and revenue analysis <br>
- Overall revenue analysis <br>
- Total order count <br>
- Payment method performance <br>
- Instagram referral performance <br>
- Phone sales by payment method 

Tools Used: <br>
- MySQL Workbench <br>
- GitHub

Key Results: <br>
- Identified top-performing products based on sales volume <br>
- Compared payment methods based on sales activity <br>
- Evaluated product performance from Instagram referrals <br>

Project Learning: <br>
Through this project, I strengthened my SQL skills and learned how to use queries to transform raw sales data into meaningful business insights. This project also improved my understanding of aggregation, filtering, grouping, and sorting in data analysis.
